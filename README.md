## こんにちは、TAKE832です 👋

COACHTECH でPHPやLaravelなどをを駆使し、プログラミングを学習中です。これからAI等が発展していく中でも、プログラミングを通して自分にしかできないことを追求していきたいと思っております。

## 使える技術
- **バックエンド**: PHP / Laravel
- **フロントエンド**: HTML5 / CSS / Blade
- **データベース**: MySQL
- **その他**: Docker / Git・GitHub
