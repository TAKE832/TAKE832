### 自分について
#### 趣味
- ゲーム（スマホでやるものが多い）
- 筋トレ・ランニング（どちらかは毎日欠かさずやるようにしている）
- 一人カラオケ（人前で歌うのは少し恥ずかしいので）
#### 長所と短所
- 長所：好きなこと・やるべきだと思ったことに対して努力を続けることができる。
- 短所：メンタルが少し弱いところ。精神が安定している方がポテンシャルを最大限引き出せると痛感しているので、日々改善のための努力を続けています。
